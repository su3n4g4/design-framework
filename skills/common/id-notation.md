# ID と記法

フェーズをまたいで同じ対象を指すときは、次の記法で統一する。

---

## 記法

| 対象 | 記法 | 例 |
|---|---|---|
| ユースケース | `UC-XX（名前）` | UC-03（検索） |
| 入出力 | `B:画面名 または API名` | B:カート画面 |
| 制御ロジック | `C:処理名` | C:購入処理 |
| データモデル | `E:Entity名` | E:在庫 |
| 概念 | `Concept:概念名` | Concept:注文 |

---

## ルール

- ユースケースの ID は 2桁の連番で振る（UC-01、UC-02…）。削除した ID は再利用しない
- データモデルの名前は、概念一覧の名称と一致させる
- 記法はテンプレート・表・コードブロックの中で使う。説明文では日本語の名称を使う
- 1つの対象には1つの名前だけを使う。別名が必要になったら、用語の変更として人間に確認する
